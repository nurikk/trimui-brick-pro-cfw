# Simulator smoke validation

The simulator smoke journey exercises launcher/session lifecycle, generated libretro and PortMaster demos, package install boundaries, protected data, suspend/resume, and recovery. It uses only generated fixture content and reports aggregate pass/fail results using only generated fixture data. Exhaustive controller reachability and host-X11 evidence are covered separately by `controller-route-coverage.py`; direct presentation fixture actions are not headed acceptance evidence.
