# Save Vault generated validation

Run the project-owned generated journey with:

```sh
cargo run --locked --release -p save-vault -- journey
```

The journey exercises simulator and production permissions, immutable versioned publication, traversal/ROM/BIOS/symlink rejection, corruption and storage-failure preservation, zero/shrink quarantine, protected retention, restore preview and explicit confirmation, cancellation, verified replacement, and sanitized controller-button presentation. It uses only generated bytes in a caller-owned temporary root.

The launcher uses the same typed boundary through `SessionBrokerClient` and exposes only aggregate history and safe preview status. Existing crash-safe resume, package, update, compatibility-recipe, and storage migration journeys remain host/static evidence. No hardware, mount, ROM/BIOS corpus, credential, or removable-filesystem POSIX claim is made.
