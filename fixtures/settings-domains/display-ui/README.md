# Generated display/UI contract fixtures

This directory contains generated, synthetic, offline contract-test data for [`docs/settings/display-ui.md`](../../../docs/settings/display-ui.md). It is not a device profile, hardware observation, HAL result, firmware claim, Artbook implementation, or production schema.

`scenarios.json` uses a fixture-local shape: each scenario supplies `input` actions and an `expectedResult` with assertions. Synthetic capability advertisements exist only to make accepted-option cases deterministic. They must not be treated as device evidence.
