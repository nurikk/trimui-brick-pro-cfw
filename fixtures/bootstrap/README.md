# Generated bootstrap fixtures

These roots are synthetic, self-contained test data for `bootstrap-probe` and `brick-recovery`. They are not device fingerprints, firmware, vendor assets, mount points, or activation payloads. Only the explicit `--simulation-fixture-root` interface may consume them.

`recovery-chord` contains a generated `.brickpro/data/recovery-button-chord` marker; `recovery-next-boot` contains a generated `.brickpro/data/recovery-next-boot` marker. The `supported` fixture is the only bootstrap-compatible profile.
