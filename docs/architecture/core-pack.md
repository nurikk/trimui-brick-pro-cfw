# TG4040 stable core-pack contract

`schemas/core-pack-v1.schema.json` and `catalog/core-packs/stable.json` define the project-authored, closed contract for the intended stable 8/16-bit and PS1 scope: GB, GBC, GBA, Mega Drive/Genesis, NES, SNES, PC Engine/TurboGrafx-16, Neo Geo, arcade, and PS1. The identifiers are public planning identities only. A core name does not select or imply an upstream package.

The catalog records exact project/package, runner, and core IDs, versions, `aarch64-unknown-linux-musl` target architecture, manifest/artifact identity, SHA-256 fields, status, and blocked reason. Every modeled package, runner, and core is explicitly `blocked`; its manifest and artifact SHA-256 values are `null`. Provenance is likewise blocked. No URL, archive, binary, source payload, signature, license clearance, ROM, BIOS byte, BIOS hash, or installable artifact is asserted.

Routing is explicit at the typed system level. `zip` is shared by the declared Neo Geo and arcade entries only because `routing.mode` is `explicit-system-selection`; an extension-only route is invalid. Rust validation normalizes every declared extension and rejects every unlisted cross-system collision before selection. The synthetic journey selects both allowed explicit `neo-geo + zip` and `arcade + zip` routes, rejects an explicit `arcade + gb` mismatch, and rejects an unlisted cross-system collision.

Systems that declare a BIOS requirement use content-free requirement metadata. The requirement is mandatory, blocked, and has no expected hash; selection rejects a missing or mismatched BIOS before activation. The pack itself is also rejected before package installation or activation. `package-manager` reuses the signed manifest and transactional install boundary and rejects every core package, with this explicit blocked core-pack state recorded for the current pack; it does not download or install a replacement. Its existing version-root promotion and atomic activation-record replacement are the upgrade boundary: failed or interrupted staging leaves the prior valid record and protected data unchanged, while an invalid current record fails before mutation. Existing protected `/roms`, `/data/saves`, and `/data/states` transaction rules remain authoritative.

Safe defaults are logical `1024x768` integer scaling, no shader, no overlay, zero frame skip, rumble disabled, `64ms` declared audio latency, and the existing built-in `default` standard input profile. Display precedence is system → profile → game → reset; input precedence is built-in → system → game → session. These are declarative orderings, not physical behavior or hardware-performance claims.

Run `emulator-catalog core-pack-journey` for the generated synthetic marker journey. It proves metadata projection, missing-BIOS rejection, blocked selection rejection, and closed identity/default/precedence validation using only inert metadata.

This is host/static contract evidence only. It does not prove TG4040 hardware, stock ABI, actual emulator or core runtime, display or input behavior, package availability, real BIOS presence, or private-corpus acceptance. No private corpus instance is read or represented.
